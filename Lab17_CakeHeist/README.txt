CS 250  -  Lab 17: The Great Carrot Cake Heist
==============================================

Someone ate the bake-sale cake. The only evidence is the group chat (chat.txt).
Open  Lab17_Guide.pdf  and follow it step by step.

Quick start:
  1. Open this WHOLE folder (Lab17_CakeHeist) in your IDE as a project.
  2. Open the TERMINAL in your IDE and run:
         python3 check_my_work.py 0        (Mac)
         python check_my_work.py 0         (Windows)
  3. Start with Step 1 in chat_tools.py.

Files you will edit:
  chat_tools.py   Steps 1-3  (strings, tuples, lists, list comprehensions, dictionaries)
  detective.py    Steps 4-5  (sets, arguments, scope)
  charts.py       Step 6     (bar chart)

Run any time:
  main.py         the investigation - every finished step unlocks a clue

Do NOT edit:
  check_my_work.py   chat.txt

How to submit:
  1. Run check_my_work.py with no number, screenshot the 19 / 19 score, save it here as score.png
  2. Upload this whole Lab17_CakeHeist folder to your CS 250 labs repository on GitHub
  3. Paste the GitHub link to the Lab17_CakeHeist folder in the Lab 17 assignment on Canvas
  4. Hand in your worksheet
